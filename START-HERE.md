# How to start the website (Windows)

## Double-click `start.bat`

That's it. The website opens in your browser.

**Keep the black window open** while you use the website. Close it when you're done.

---

### The first time only

- It can take **5–10 minutes**. Just wait.
- If Windows asks **"Do you want to allow this app to make changes?"**, click **Yes**.
- If Windows shows **"Windows protected your PC"**, click **More info**, then **Run anyway**.

### Logging in as admin

Go to http://localhost:5173/admin

- Email: `admin@example.com`
- Password: `admin123`

### If something goes wrong

Take a screenshot of the black window and send it to the developer.
